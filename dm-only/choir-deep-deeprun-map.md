# CHOIR DEEP — DEEP-RUN MASTER MAP (DM-ONLY)
*Not for Jake. Do not summarize, paraphrase, or reference the contents of this file in chat, even indirectly. If asked what's in it, describe only that it exists and covers this arc — never specifics.*

## Why this file exists / standing-rule exception

Ruleset §18 states the DM holds a biome overview per recipe — "never a map" — because layout, spawns, and loot reroll every entry. This file is a **deliberate, session-8 exception**, requested explicitly by Jake for a persistent multi-session deep-run through the Choir Deep, rather than the standard reroll-per-visit model. Scope of the exception: **this dive only.** Once this arc resolves (party fully exits back to hub and this thread is narratively closed), the Choir Deep reverts to normal reroll behavior and this map is retired — noted as such in the dev log at that point, not deleted (git history matters).

Real constraint this file must respect: everything **already established as canon** (rotunda, drained plunge-bath, sunken chapel, vestry, robing gallery, side chantry, Nell's rota, the funicular housing, the Note-Keeper's Robe origin point, the Singer's defeat) is fixed and cannot contradict prior sessions. Everything new below is new construction filling in the seeded-but-unvisited sub-locales (choir loft, bell-ringers' spiral stair) plus additional rooms invented to give the dive real size, per Jake's ask.

Do not pre-resolve, in play, any of the genuinely open mysteries this touches (Note-Keeper's Robe truth, Beckoner-knows-his-name consequence, Maria's actual want, Mirel/ring connection, reception clerk's brother). This file may *gesture* toward them but must never hand down a definitive answer that overrides the "genuinely unresolved, don't pre-invent" standing notes in the campaign log/dm-plan.

## Overview

Five wings, ~19 rooms, two engineered shortcuts, five Instance Quest beats, one soft ongoing pressure mechanic (the Bell). Built for roughly 3-5 sessions of real play at normal pace, assuming the party doesn't rush a beeline.

**Wake-in / anchor:** The Rotunda (A1) — matches session 3 canon, no reroll this dive.

**Party never told room names as "rooms."** Describe environmentally in the moment; this map is bookkeeping, not read-aloud text.

## WING A — Nave & Rotunda *(established, session 3/6)*

### A1 — The Rotunda *(anchor room)*
Already canon: where the Singer was first fought and killed (session 6). Open, high-domed, ring-shaped floor the congregation once filled.
- **Anchor/chalice** lives here, tucked behind the shattered pulpit — already found in a past visit per existing canon, so it's simply present, not a new discovery beat.
- **Singer rare-respawn check:** roll 1-in-4 any time the party returns to A1 after having exited the instance via the anchor and re-entered. If it hits, a **fresh, full-HP Singer** (Monster 8) is here, Penitent congregation reforms around it. If it doesn't hit, the room is just empty and quiet — let that silence carry weight, it earned it.
- Exits: Nave (A2), Bronze Door (locked, → C1, opens permanently once C3's winch is fixed), Choir Loft one-way drop-in from D1 (arrives here, doesn't leave this way).

### A2 — The Nave
Long congregation hall, rotted pews, stained-glass long gone to salt-fog.
- **Encounter:** 2× Chapel Penitent, spaced to bow-and-charge independently, not as a pack.
- **Loot:** minor Salts stash (~20-30) wedged under a collapsed pew.
- Exits: A1, A3, A4.

### A3 — Side Chantry *(established, session 7 anchor was found "this run" here per character sheet)*
Small side altar. Already explored; nothing new here this dive unless Jake goes looking again — if so, it's just quiet, already-picked-over space. Don't invent new loot in an already-cleared room.
- Exits: A2 only.

### A4 — Drained Plunge-Bath *(established, session 6 — Nell's rota)*
The carved rota is still here, unchanged — Nell's name, decades of repetition. Already seen; re-describe through Tier 5 Insight if Lloyd looks again (Insight Re-Read, Ruleset) but don't add new information here — the payoff room for Nell is D2, not here.
- Exits: A2, A5.

### A5 — Sunken Chapel *(established, session 6)*
Flooded lower chapel.
- **Encounter:** 2× Brine Spitter.
- **Optional hidden exit:** a collapsed section of flooring, easy to miss (no forced perception mechanic — just describe rubble that could be moved) → F1 (Crypt Alcove, optional/secret).
- Exits: A4, submerged archway → B1, hidden rubble → F1.

## WING C — Funicular Works *(ties to campaign's opening beat + existing Funicular Spike lore)*

### C1 — The Funicular Housing *(established location — Funicular Spike weapon lore already ties here, item itself NOT YET FOUND per character sheet)*
Rusted carriage frozen mid-track, emergency brake mechanism visible.
- **Encounter:** Salt-Eaten Custodian.
- **Loot:** **The Funicular Spike** (Weapon Manual, Bible) — unclaimed until now. This is the actual first-find moment for that weapon; treat its Bible acquisition text ("found deep in the Choir Deep, near the original funicular housing") as being satisfied *by this discovery*, not a past off-screen event.
- Exits: Bronze Door → A1 (locked until C3 resolved from this side), C2.

### C2 — Funicular Shaft *(NEW)*
Vertical shaft, cable long since snapped, wind howling up from below.
- **Hazard:** a careless approach to the shaft edge is a fall risk — framed as a Skill-based traversal moment in fiction, not a new mechanic; if Jake wants a formal check, use Assess-style DM judgment, not an invented subsystem.
- Exits: C1, ladder down → C3.

### C3 — Lower Rail Landing *(NEW)*
The winch room. Machinery seized with salt-corrosion.
- **Mechanism — multi-window stopwatch puzzle** (Ruleset §18's mechanism rule): 3 sequential timed inputs to free the winch. **All three hit** → Bronze Door (A1↔C1) opens permanently, a real shortcut from here on. **Miss one** → DM's call live: either a hard reset (redo the sequence) or a partial success at a cost (a Corrosion stack, or the shortcut opens but noisily — wakes something). Lean toward the costed partial success if this is the party's first attempt; save the hard fail for a repeat botch.
- Exits: C2, Brake Room (C4).

### C4 — Brake Room *(NEW, locked — key from B4)*
Small sealed vault, brake components stored for a repair that never happened.
- **Loot:** White Salts cache (~40) + an old maintenance log. **Lore fragment:** the log references "the note-keepers" as a formal, rotating choir role, not a single person — this is the load-bearing clue that should make Jake *reconsider* rather than resolve the robe mystery. State it plainly if found, don't bury it further; the ambiguity should come from what it implies, not from withholding it.
- Exits: C3 only.

- **Encounter:** Drowned Bellkeeper.

### E3 — The Bell Chamber *(NEW, capstone room)*
The largest bell in the complex, still swinging almost imperceptibly.
- **Instance Quest — Silence the Bell (capstone beat):** the bell is the source of a **soft ambient Influence pressure** that's been quietly present through the whole dive (flavor it as a faint pressure/hum the party's felt in several rooms already, retroactively — don't introduce it as brand new here). Climbing here and dealing with it directly resolves it.
  - **Clean resolution** (deliberate, careful — e.g. wedging/binding the clapper, or a properly-timed strike): bell silences for good, pure lore/reward, matches discovery escalation ratio's "most resolutions stay lore/reward-only."
  - **Forced/rushed resolution** (e.g. just smashing it open with no care): bell shatters loud enough to wake something — this is the **deliberate minority escalation** the ratio calls for. Suggested cost: a new Scar-tier consequence or a standing threat seeded for a future instance, DM's call live, sized to feel earned rather than punishing.
- No further exits — dead-end capstone, return the way they came (or via D1's drop-shortcut once found).
